# Nency Kalpeshbhai Patel - Portfolio

A cinematic, interactive personal portfolio website showcasing my projects, skills, and experience as a B.Tech Computer Science Engineering student (Class of 2028). Built with React, TypeScript, Vite, Framer Motion, and Tailwind CSS.

## 🚀 Live Preview
*Local development running on `http://localhost:5173/` after setup.*

## ✨ Features
- **Dynamic Cinematic Design**: A premium, motion-rich interface built using Framer Motion and modern UI/UX principles.
- **Projects Showcase**: Interactive cards detailing architectural metrics, tech stack, and GitHub repositories.
- **Skills Matrix**: A comprehensive breakdown of frontend, backend, database, and soft skills.
- **Interactive Experience Timeline**: A step-by-step route map of my education, hackathon participations, and certifications.
- **Direct Contact System**: A built-in terminal-style form and direct links to connect via Email, LinkedIn, and GitHub.

## 🛠️ Built With
- **Frontend Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Build Tool**: Vite
- **Smooth Scrolling**: Lenis

## 💻 Running Locally

To run this project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/N3ncy/cinematic-portfolio-main.git
   cd cinematic-portfolio-main
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
